# DentPlan

Интерактивный планировщик помещений с двумя профилями: стоматологическим и общим. Приложение поддерживает план, 3D-визуализацию, расстановку оборудования, выходы и экспорт.

## Профиль проекта

В боковой панели выберите тип помещения:

- **Стоматологическое помещение** — приложение показывает предварительные ориентиры и темы, которые нужно проверить у профильных специалистов. Это не нормативное заключение.
- **Общее помещение** — стоматологические рекомендации скрыты; геометрия и пользовательские ограничения продолжают работать.

Профиль сохраняется в поле `profile` файла проекта и в поле `projectProfile` выгрузки данных. Допустимые значения — `dental` и `general`. Старые проекты без поля профиля открываются как `dental`; неизвестное значение отклоняется до замены текущего проекта.

## Как открыть

Для быстрой проверки откройте `index.html` в браузере.

Надёжнее запустить локальный сервер из папки проекта:

```bash
python3 -m http.server 8000
```

После этого откройте <http://localhost:8000>.

Для 3D-режима, иконок и экспорта PDF нужен интернет: приложение загружает внешние библиотеки через CDN.

В блоке **«Проект»** кнопка **«Новый проект»** начинает чистый чертёж после
подтверждения. Размер помещения и профиль сохраняются для нового листа, а уже
скачанный `.json` не удаляется — его можно снова выбрать через **«Открыть
проект»**.

## Выгрузка данных

Кнопка **«Экспорт»** формирует PDF-отчёт, JSON со структурированными данными и CSV со списком стен, проёмов и оборудования. JSON-контракт: `schema: "dentplan-data-export"`, `version: 1`; координаты `x/z` и длины заданы в метрах, площади — в м², `rot` — в радианах. Для отчётов также есть производное поле `rotationDeg`. Профиль добавлен совместимо, без повышения версии контракта.

Площадь пола для пустого или незамкнутого наружного контура равна `null`. По умолчанию площадь стен считается по одной плоскости каждой стены при высоте 3 м; из неё вычитаются двери и эвакуационные проёмы высотой 2,1 м и окна высотой 1,5 м. Эти значения можно изменить в настройках проекта.

В блоке **«Параметры расчёта»** можно изменить высоту стен, дверей, эвакуационных проёмов и окон. Для стен допустим диапазон 2–6 м, для проёмов — 0,5–4 м. Настройки сохраняются в поле `calculation`; старые файлы без этого поля открываются с прежними значениями.

## Работа с предметами

Выберите объект в каталоге, чтобы добавить его на план. Заголовок каждой группы сворачивает и разворачивает её содержимое; кнопка «Свернуть всё / Развернуть всё» управляет всем каталогом. Предметы можно перетаскивать в 2D и 3D, двигать стрелками с шагом 10 см (с `Shift` — 1 см), дублировать клавишей `D` и удалять клавишей `Delete`. Точный угол задаётся в панели выбранного предмета. Габариты автоматически остаются в пределах контура.

## Редактирование помещения

В режиме «Стены» сначала выберите первый инструмент «Выбор и перенос». При наведении на дверь, окно или эвакуационный проём его графика подсвечивается янтарным цветом и появляется подпись типа; нажимайте прямо на этот объект, чтобы выбрать его. Нажимайте на линию стены вне проёма, чтобы выбрать стену. Выбранный объект подсветится красным, а карточка с типом появится снизу. Клавиши `1–7` выбирают инструмент. Клик по двери, окну или эвакуационному проёму выделяет только этот объект красным; кнопку корзины в карточке или `Delete/Backspace` можно использовать для его отдельного удаления, не затрагивая стену и соседние проёмы. Дверь или окно перемещаются вдоль своей стены; перетаскивание поперёк удерживает проём на ближайшем допустимом месте и не переносит стену. Чтобы перенести всю стену, нажимайте на свободный участок её линии. Точки и стены можно перетаскивать; белые ручки меняют длину стены или ширину проёма. `←/→` двигают выбранный проём, `+/−` меняют его ширину или длину выбранной стены, кнопка `↻ 180°` разворачивает дверь или окно на 180° (это не зеркальное отражение). У двери отдельные кнопки **«Петли: слева/справа»** и **«Открывание: внутрь/наружу»**: первая переносит крепление на другой конец проёма, вторая меняет сторону открывания; обе операции сохраняют положение и ширину проёма. `Shift` уменьшает шаг переноса проёма до 1 см.

При рисовании нового сегмента от узла с соседней стеной, а также при переносе
узла или конца стены, рядом с курсором показываются фактический угол между
сегментами и его отклонение от 90°: например, `угол 88,00° · отклонение 2,00°`.
Это геометрическая подсказка, а не проверка строительных норм.

Кнопки рисования подписаны **«Внутренняя перегородка»** и **«Наружная
стена»**: обе создают прямые сегменты цепочкой, но записывают разные типы
стен. При рисовании или переносе перегородки рядом с курсором отображается
расстояние до внешнего контура: при движении по горизонтали — слева и справа,
при движении по вертикали — сверху и снизу. Для диагонального движения
показывается расстояние по нормали, если направление нельзя определить
однозначно.

Планировщик даёт предварительные ориентиры для макета. Итоговое соответствие санитарным и пожарным требованиям должен подтвердить профильный специалист.

Для стоматологического профиля список тем опирается на официальную запись в каталоге Минстроя об изменении № 5 к СП 158.13330.2014 и официальную публикацию изменения СП 2.1.3678-20 от 20.03.2024 (ID `0001202407120010`); источники проверены 09.09.2026. Это ссылки на записи документов, а не цитаты отдельных пунктов. Численные значения намеренно не автоматизированы до отдельной проверки действующих редакций специалистом.

## Чертёж-подложка

Загрузите PNG, JPG или PDF кнопкой «Загрузить чертёж» или перетащите файл на план. Для PDF используется первая страница. После загрузки:

- включите режим подложки, поверните и переместите её;
- откалибруйте масштаб по отрезку с известной длиной;
- перейдите в режим «Стены» и обведите контур;
- сохраните проект в `.json`, чтобы восстановить подложку и её настройки.

Для PDF приложение динамически загружает [PDF.js 6.3.289](https://mozilla.github.io/pdf.js/) с CDN (лицензия Apache 2.0) и растеризует первую страницу в canvas. Проект работает без сборки, поэтому при отключённом интернете PDF не откроется, а PNG/JPG продолжат работать. После рендеринга PDF-подложка сохраняется в JSON как PNG-изображение вместе с её масштабом, положением и поворотом.

## Структура

- `index.html` — всё приложение: разметка, стили и JavaScript.
- `README.md` — инструкция по запуску и работе с репозиторием.
- `PROJECT_PLAN.md` — краткий план, статусы и порядок синхронизации рабочих чатов.
- `TASK_CARDS.md` — подробная карточка каждого чата: цель, сделанное, проверки,
  ограничения и следующий шаг.
- `tests/smoke.test.js` — быстрые проверки синтаксиса и защитных сценариев.
