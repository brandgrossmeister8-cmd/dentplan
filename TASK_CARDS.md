# DentPlan — карточки задач и рабочих чатов

Этот файл — подробный журнал рабочих задач проекта. `PROJECT_PLAN.md` показывает
краткий текущий статус, а здесь по каждой ветке видно, что именно сделано,
какими изменениями это подтверждено и что ещё нужно проверить.

## Как читать карточку

- **Состояние** — текущий статус результата в главной ветке.
- **Сделано** — принятые изменения, без предположений о незавершённой работе.
- **Проверка** — что уже проверено автоматически и что ещё требует проверки в браузере.
- **Открытые вопросы** — ограничения или решения, которые нельзя считать закрытыми.
- **Следующий шаг** — ближайшее действие главного чата или рабочей ветки.

После каждого отчёта рабочей ветки главный чат проверяет diff и тесты, переносит
принятый коммит в `main`, а затем обновляет соответствующую карточку и
`PROJECT_PLAN.md`. Поэтому карточка не заменяет code review: она фиксирует его
результат понятным языком.

### Цель

Свести результаты рабочих чатов в одну проверенную ветку, следить за общим
контрактом проекта, фиксировать статусы и возвращать рабочим чатам уточнения.

### Сделано в `main`

- Приняты и проверены срезы по подложке, профилям, виду, оборудованию,
  выгрузке, стенам и проёмам.
- Добавлен общий план проекта в `PROJECT_PLAN.md`.
- Для каждой рабочей ветки заведена эта карточка с результатом, проверками и

- После последнего исправления проёмов `node tests/smoke.test.js` проходит,
  рабочее дерево чистое.

### Правило приёма результата

1. Рабочий чат сообщает цель, файлы, коммит, проверки, ограничения и вопросы.
2. Главный чат просматривает diff и запускает smoke-тесты.
3. Только принятый результат переносится в `main`.
4. Карточка задачи и `PROJECT_PLAN.md` обновляются сразу после приёма.
5. Публикация в GitHub выполняется только после отдельного решения Риты.

подложке, профилям и выгрузке. После этого можно закрыть карточки проверки,
уточнить расстояния для стены и отдельно решить вопрос публикации через GitHub.
